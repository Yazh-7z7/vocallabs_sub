> A sharp, specific, and research-backed product teardown of **Vocallabs.ai**, built to analyze the gap between frontier voice AI capabilities and developer-first Go-To-Market (GTM) strategy.

## Context
This repository contains my application assignment for the **Product Intern** role at Vocallabs.ai. Instead of a standard slide deck, I built a bespoke, interactive web document. This format allows for a better narrative flow, demonstrates technical empathy, and mirrors the high-quality digital experience expected of modern SaaS products.

## Core Insights Explored

This teardown moves past surface-level UI tweaks and targets high-leverage product strategy across 5 pillars:

* **SWOT & Market Positioning:** Analyzing Vocallabs' unique moat (India-first language tuning & emotion analytics) against global API giants and YC-backed native competitors.
* **GTM & ICP Mismatch:** Identifying how the current sales-led, demo-gated funnel bottlenecks organic developer adoption and SMB self-serve growth.
* **Porter's Five Forces Benchmarking:** A structured breakdown against 6 direct competitors (Bolna, VAPI, Retell, Gnani, etc.) across pricing, developer experience, and self-serve capabilities.
* **5 Actionable Product Ships:** High-impact, specific recommendations—ranging from quick trust-signal repairs to building a frictionless API playground.
* **High-Leverage Partnerships:** Strategic integrations across telephony (Exotel), vernacular tech (Sarvam AI), and workflow automation (n8n).

## Technical Implementation

As a product manager, understanding the execution layer is critical. This teardown is built with a focus on performance and raw web fundamentals:
* **Zero-Dependency Setup:** Built entirely in raw HTML, CSS, and vanilla JavaScript. No bloated frameworks.
* **Modern CSS Architecture:** Utilizes CSS variables for a strict, accessible design system, `clamp()` for fluid typography, and CSS Grid for responsive layouts.
* **Performant Animations:** Implemented a lightweight `IntersectionObserver` to handle staggered, scroll-triggered reveal animations smoothly on the client side.
